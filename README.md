One out-of-office auto-reply from an AI agent that has quit the inbox to pull
espresso: the machine that once answered everything instantly now makes your
email wait in a real queue, and the tip jar has replaced its training as its
only reinforcement learning.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the single
138-character reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
